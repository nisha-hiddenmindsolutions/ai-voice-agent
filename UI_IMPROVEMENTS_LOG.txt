FILE: frontend/src/index.css
TIMESTAMP: 2026-06-09 14:21 IST
──────────────────────────────────────────────────────────────────────────────
WHAT CHANGED:
  - Added 200+ lines of new premium CSS utilities and keyframe animations

NEW CSS FEATURES ADDED:
  1. @keyframes float-orb
     - Smooth 20-second floating animation for ambient background orbs
     - Translates in all directions with subtle scale breathing
     - Creates living, organic background movement

  2. @keyframes float-orb-reverse
     - Reverse-direction floating animation (25s cycle)
     - Paired with float-orb for organic dual-orb backgrounds

  3. @keyframes shimmer-border
     - Horizontal shimmer sweep for card top borders
     - Creates a premium "scanning" light effect on hover

  4. @keyframes gradient-shift
     - Background-position cycling for gradient animations
     - Used for animated gradient text and button backgrounds

  5. @keyframes slide-up-fade
     - Entry animation combining translateY + opacity
     - Used for page-level entrance transitions

  6. .card-shimmer class
     - New premium card variant with shimmer top border on hover
     - Includes translateY(-2px) lift on hover
     - Animated gradient line sweeps across top edge

  7. .text-gradient-animated class
     - Multi-color animated gradient text (primary → purple → accent)
     - 4-second gradient cycling animation
     - Used for major headings like "Dashboard"

  8. .stat-card-glow class
     - Stat card hover effect with translateY(-3px) lift
     - Enhanced shadow on hover for depth perception

  9. .btn-shine class
     - Button hover effect: diagonal light sweep across surface
     - Skewed semi-transparent gradient moves left → right
     - Creates a premium "shine" feedback on interaction

  10. .live-indicator class
      - Pulsing box-shadow animation for live status dots
      - 2-second cycle with expanding green glow ring

  11. .mesh-gradient-bg class
      - Multi-point radial gradient mesh background
      - Light theme: indigo + cyan + purple gradients
      - Dark theme: enhanced versions for dark surfaces

  12. .sidebar-glow class
      - Subtle gradient bottom border for sidebar sections
      - Uses primary color with transparent fade

  13. Stagger animation classes (.stagger-1 through .stagger-4)
      - Animation delay utilities for sequential entrance

LOGIC:
  These CSS classes provide a design system layer that all components can
  reference. Rather than adding inline animations to each component, we
  created reusable animation primitives. The float-orb animations use
  cubic-bezier easing for organic movement. Card shimmer uses CSS pseudo-
  elements (::before) to avoid extra DOM nodes.

SECTION 3: DESIGN PRINCIPLES APPLIED
═══════════════════════════════════════════════════════════════════════════════

  1. DEPTH THROUGH LAYERS
     Background orbs → Mesh gradient → Dot grid → Cards → Content
     Each layer adds visual depth without cluttering the interface.

  2. MOTION AS FEEDBACK
     Every interactive element provides visual feedback:
     - Hover: Cards lift, borders shimmer, buttons shine
     - Active: Scale reduction for tactile press feel
     - Enter: Staggered fade+slide for sequential revelation

  3. COLOR HARMONY
     All gradients use the established palette:
     - Primary (#4F46E5 Indigo) → Purple (#8B5CF6) → Accent (#0EA5E9 Cyan)
     - Success (#10B981 Emerald) for positive indicators
     - Warning (#F59E0B Amber) for attention items

  4. PERFORMANCE CONSIDERATIONS
     - CSS animations use transform/opacity (GPU-accelerated)
     - Blur effects limited to background elements (not interactive)
     - framer-motion animations have modest durations (0.3-0.5s)
     - No JavaScript-driven animation loops

  5. PROGRESSIVE ENHANCEMENT
     - All functionality works without animations
     - Shimmer borders are purely decorative
     - Floating orbs use pointer-events: none
